Create the bot with the gate already inside

AgentKit has no “pre-filled create agent” web form — you scaffold code. We give you the next-best path: open this repo with the gate already wired, run two commands, then set rules when you want. Until a mandate exists, spends fail closed; other agent work still runs.

  1. Open the starter — GitHub Codespaces (browser IDE) or clone the repo. Gate code lives in createGatedAgentKit; demo script: npm run agent:gated.
  2. Run the gate path — in the project: npm install, then terminal A npm run http:gate, terminal B npm run agent:gated.
  3. Set rules when ready — draft a mandate in this UI (or applyPolicy). Live Base txs need CDP keys from Coinbase CDP; OpenServ host is npm run dev.
